Get started

How to run it locally

You'll need Python 3.10+, AWS credentials, and PortAudio on your system.

1

Clone the repo

git clone https://github.com/YOUR_USERNAME/jozi-voice-buddy.git
cd jozi-voice-buddy
2

Create a virtual environment

python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
3

Install dependencies

pip install -r requirements.txt
4

Configure AWS credentials

Run aws configure and set your region to us-east-1. Then enable Amazon Nova Sonic model access in the Bedrock console ↗. 

aws configure
5

Run Jozi Buddy

Put on headphones (or echo cancellation will handle it), then:

python voice_agent.py

Press Ctrl+C to end the conversation.
